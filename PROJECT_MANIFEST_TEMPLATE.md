1. Read `docs/PROJECT_OVERVIEW.md` first.
2. Ask the participant targeted follow-up questions only for fields the overview does not answer. Prefer yes/no or multiple-choice questions over open-ended ones.
3. Fill every section; flag uncertainty with `TBD — <question>` so the participant can resolve it later.
4. Commit the result at `docs/PROJECT_MANIFEST.md` with a message of the form `docs: generate project manifest from overview`.

# Project Overview: [Your Project Name]

Fill this out before you start the curriculum. Keep it short — each section should be a few sentences or a short list. Your local coding agent will read this during L1 (plus ask follow-up questions) to generate the structured [`docs/PROJECT_MANIFEST.md`](./PROJECT_MANIFEST_TEMPLATE.md) every factory agent will then consume.

See [`reference-project/fired-up-pizza/docs/PROJECT_OVERVIEW.md`](../reference-project/fired-up-pizza/docs/PROJECT_OVERVIEW.md) for a completed example.

## 3. Scope & constraints

What is explicitly in or out of scope? Note any technology choices, compliance requirements, or architectural constraints already in place.

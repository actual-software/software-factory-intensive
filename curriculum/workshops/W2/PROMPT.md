# W2 Facilitation Prompt

Use this prompt with a local coding agent if you want help drafting the W2 factory map.

```text
You are helping me design a small software factory for my project.

Read:
- my project overview
- my project manifest if present
- packs/lessons/L3/formulas/mol-feature-delivery.toml
- packs/lessons/C1/formulas/mol-release-delivery.toml

Write activities/workshops/W2/factory-map.md with:
- role responsibilities
- artifacts each role reads and writes
- formula step IDs
- binding-qualified targets like factory.planner
- dependencies between steps
- done criteria
- risks where the project may need custom prompt or validation rules

Keep the design centered on self-contained lesson factory packs. Do not propose a shared pack topology.
```

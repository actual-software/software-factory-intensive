# Troubleshooting Guides

Topic-scoped guides for issues participants hit while working through the Software Factory Intensive curriculum. Each guide is organized as `Symptom → Cause → Fix` so a reader can jump to a heading anchor and see exactly what to do.

## Guides

| Topic | When to share this link |
|---|---|
| [Beads (`bd`)](beads.md) | Issues related to bead workflow, agent handoffs, or bead commands. |
| [CLI coding agents](cli-coding-agents.md) | Problems interacting with CLI-based coding agents or slash commands. |
| [Gas City (`gc`)](gas-city.md) | General troubleshooting for Gas City setup, commands, agent lifecycle, or environment issues. |
| [tmux](tmux.md) | Terminal usability or session management issues, especially with tmux. |

## Adding a new guide

1. Create `troubleshooting/<topic>.md`.
2. Add a row to the table above.
3. Write each entry as `## Issue: <short title>` with **Symptom**, **Cause**, **Fix** sub-sections so heading anchors like `cli-coding-agents.md#issue-gc-command-not-found` are easy to link.
